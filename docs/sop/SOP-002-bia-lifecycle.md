# SOP-002 – Business impact analysis lifecycle
**Owner:** Business continuity manager · **Aligned to:** ISO 22301 / ISO/TS 22317 concepts (no certification implied)
1. **Screen** every new project at intake (*Project → BIA screening*). Score ≥5 → full BIA; 2–4 → light; <2 → none (recorded).
2. **Assess** impact severity (0–5) for each category and horizon (1h, 4h, 1d, 3d, 7d). Confirm the tolerance threshold with the process owner.
3. **Set objectives:** MTPD is derived; set RTO ≤ MTPD, RPO and MBCO.
4. **Map dependencies** (people, applications, infrastructure, data, third parties) with demonstrated recovery and data-loss capability; flag single points of failure.
5. **Define recovery strategies** and record test date, result and evidence.
6. **Resolve findings** until no blocking errors remain, then **submit**; the BC manager approves; the next review date is set.
7. **Review** when notified (or after material change). Any edit to an approved BIA returns it to draft for re-approval.
